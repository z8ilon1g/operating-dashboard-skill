# 数据表字段模板

> 一张屏一张表。表是图的唯一数据源，图上不做二次计算。

---

## 1. 通用表结构

| 列 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 顺序 | 数字 | ✅ | 图的排序依据 |
| 项目 / 阶段 / 节点 | 文本 | ✅ | 图上的标签 |
| 实际值 | 数字 | | 空 = 待提取，**不填 0** |
| 单位 | 单选 | ✅ | 万吨 / 亿元 / 元每吨 |
| 目标值 | 数字 | | 每个指标**各自**的目标，不许共用 |
| 完成率_% | 数字 | | 1 位小数 |
| 对基准_pp | 数字 | | 对时间进度/目标的差 |
| 数据状态 | 单选 | ✅ | 待提取 / 部分 / 已确认 |
| 可信度 | 单选 | | A 计量 / B 推算 / C 估算 |
| 备注 | 多行文本 | | 写规则与例外，不写废话 |

---

## 2. 四种表的专用字段

### 2.1 流量-目标型（如五段达成）

```
顺序 | 阶段 | 完成率_% | 实际 | 单位 | 目标值 | 对时间进度_pp | 判定 | 备注
```
备注里必须写一句：**「N 段各有独立目标，完成率不可横向互算」**（如果成立）。

### 2.2 库存-节点型（如库房）

```
仓ID | 顺序 | 库存节点 | 类型 | 盘存量 | 计量方式 | 距校准_天 | 可信度 | 数据状态 | 备注
```
合计行单列（`*-SUM`），明细行留空，备注写「禁止分摊」。

### 2.3 台账型（如校准台账）

```
批次 | 日期 | 对象 | 区间起 | 区间止 | 初始值 | 校准值 | 差值(公式) | 数量 | 影响量(公式) | 金额(公式) | 状态 | 单据号 | 数据状态 | 可信度 | 录入批次 | 备注
```
公式字段不许手填；单位约定（如品位存 23.5 还是 0.235）写进表头说明。

### 2.4 参数型

```
参数ID | 参数名 | 值 | 单位 | 来源 | 状态
```
状态列写「待财务确认」等；图上引用的每个参数都必须能追溯到此页。

---

## 3. 字典页

```
类别 | 取值 | 含义 | 用于
```
所有单选字段的取值都要在此登记。新增枚举时同步补这里，否则单选会出现两个同名项。

---

## 4. 说明页（0_说明）必写

1. 用途与使用步骤
2. 三条硬规则：空 ≠ 0；金额单位统一；参数改动后公式是否重算
3. 哪些表是空表、为什么空着是对的
4. 口径声明（起算日、业务月定义）

---

## 5. 导入版

工作版有标题行/说明行时，另存一版：

- 去掉标题行、说明行、说明页
- 表头在第一行
- 保留列宽与表头样式
- 文件名加 `-导入版`

理由：多数导入工具默认"首行即表头"，不处理会让字段名变成标题文字。
