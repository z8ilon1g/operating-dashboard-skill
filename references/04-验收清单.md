# 验收清单

> 用法：每屏建完走「单屏验收」；全部建完走「总验收」。
> **每条必须附实测值或证据**，写「是」不算，写「应该是」不算。

---

## 一、单屏验收（每屏建完即走）

### 1. 结构

- [ ] 标题是一句结论，不是图表名
- [ ] 副标题写清路径/范围
- [ ] 右上角有口径行（含起算日）
- [ ] 页脚有「数据时点 YYYY-MM-DD」

### 2. 数值

- [ ] 图上每个数在取数表里有对应单元格
- [ ] 合计/闭合关系成立（如 15.00 − 1.69 − 2.20 − 0.97 = 10.14）
- [ ] 百分比与分子分母一致（保留 1 位）
- [ ] 各段分母各不相同且已写明

### 3. 空态

- [ ] 缺数据的元素显示「待提取/待校准」，不是 0
- [ ] 空态下不出现任何示例数
- [ ] 空态的字体颜色可读（深灰，不是浅灰）

### 4. 表达

- [ ] 颜色不超过 4 支
- [ ] 没有用同类图表达不同关系（如用饼图表示流动）
- [ ] 标签没有被裁、没有换行、没有与数值重叠
- [ ] 表格末行完整可见

### 5. 文字与数同源

- [ ] 图注里的每个数字都能从图/数组算出来
- [ ] 没有「基本一致」「大致」这类表述
- [ ] 参数来源可追溯到参数页

---

## 二、总验收（全部屏建完）

### 屏与导航

- [ ] N 屏齐全，导航可切换，切换后只有目标屏 active
- [ ] 每屏页脚都有数据时点，无「期末/当前/截至」裸词
- [ ] 全站口径不混：YTD 屏与时点屏在页面上分得开

### 数据层

- [ ] 每张表行数与设计一致，无多余空行
- [ ] 合计行有值、明细行为空
- [ ] 数字列是数字类型
- [ ] 字典页覆盖全部单选值

### 关键数值（按项目填）

- [ ] 主链闭合
- [ ] 五段各有目标值
- [ ] 资金占用不含估算存货
- [ ] 敏感度无重复驱动
- [ ] 评分数组与合计一致

### 响应式

- [ ] 1280 宽无横向滚动
- [ ] 1520 宽无横向滚动
- [ ] 卡片内文字无溢出

### 交付物

- [ ] 图稿 PNG（规格基准）
- [ ] 逐图说明
- [ ] 搭建指令
- [ ] 取数表（工作版 + 导入版）
- [ ] 进度档记录本轮修掉的问题

---

## 三、回执格式（给智能体）

```markdown
一、做了什么
   表/字段/行数、改了哪几处

二、实测值
   逐项：项目 / 实测值 / 基准值 / 一致或差异

三、异常
   做不到的逐条写，没有写「无」

停。
```

**判「未核」的三种写法**：

- 「基本一致」「大致符合」「应该是」
- 只报目标值、不报实测值
- 只给结论、不给证据（表名+行 / 屏号）

---

## 四、验收之后

1. 把本轮修掉的真问题写进项目档：**谁发现的、怎么复算的、改成什么**
2. 口径决策落进文档，不要只留在对话里
3. 已知欠账（快照、未同步的数据、参数待确认）单独列一节
